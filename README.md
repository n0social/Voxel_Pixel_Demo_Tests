# Voxel & Pixel Demo Tests

Sandbox repo for small **pixel** and **voxel** demos while learning game dev. Each demo is meant to be runnable on its own—quick experiments, not one monolithic game.

## Projects in this repo

| Item | What it is |
|------|------------|
| **Demos** (planned) | Isolated pixel/voxel learning runs under `demos/` |
| **[Voxel Planet](docs/BUILD_PLAN.md)** | Separate browser voxel-worlds concept—not the main purpose of this repo; see `docs/BUILD_PLAN.md` for that product direction |

## Layout (intended)

```text
demos/           # pixel & voxel demo runs
docs/            # notes and project specs (e.g. Voxel Planet)
```
